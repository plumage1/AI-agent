# Redis 面试知识库

## Redis 持久化
Redis 持久化主要有两种方式：RDB 和 AOF。RDB 是定期生成内存快照，恢复速度快，但可能丢失最近一段时间的数据。AOF 是记录每次写操作，数据更完整，但文件可能更大，恢复速度可能更慢。

## Redis 缓存雪崩
缓存雪崩是指大量缓存 key 在同一时间失效，导致大量请求直接打到数据库，造成数据库压力瞬间升高。常见解决方案包括给 key 设置随机过期时间、热点数据不过期、限流降级、提前预热缓存。

## Redis 缓存穿透
缓存穿透是指请求查询一个数据库和缓存中都不存在的数据，导致请求每次都打到数据库。常见解决方案包括布隆过滤器、缓存空值、接口参数校验。
